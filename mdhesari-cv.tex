\cvsection{Profile}

I enjoy working on the parts of software that are easy to underestimate:
data consistency, system boundaries, integrations, failure cases, and the
trade-offs behind seemingly simple decisions. Over the past 5 years,
I've built backend systems with Go and PHP and taken them from design to
production. My current focus is becoming exceptionally good at building
simple, reliable systems that continue to work as complexity grows.

\cvsection{Experience}

\job{Simorgh}{Senior Backend Engineer · remote}{Jan 2025 – Sep 2026}

\begin{itemize}
    \item Designed and implemented multi-tenancy and tenant-scoped RBAC,
        replacing the previous global admin model. Tenants share one PostgreSQL
        schema with row-level \code{tenant\_id} isolation and tenant-specific settings.

    \item Designed and built an ERP integration that imports user and contract
        data from customer-managed SQL Server, Oracle, MySQL, and PostgreSQL databases,
        with credentials stored in HashiCorp Vault.

    \item Primary backend developer for the Go platform
        (Gin, GORM, PostgreSQL, MinIO). Refactored the inherited architecture
        to simplify package boundaries and eliminate recurring import-cycle problems.

    \item Introduced structured logging, request correlation IDs, ELK-based
        log aggregation, and production metrics with Prometheus and Grafana.
        Reduced average production debugging time from 15 minutes to 5.

    \item Restructured normalized JSON data into relational PostgreSQL tables,
        adding foreign keys and indexes and eliminating N+1 query patterns.

    \item Built the fiat payout module for the company's asset-tokenization platform,
        using Go and gRPC with provider-specific gateway drivers for two payment providers.
\end{itemize}
